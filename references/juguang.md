# 聚光官方说法（写选题、写稿前对一下）

来源：聚光帮助中心 ad.xiaohongshu.com/next_help（不用登录也能看），2026-10-31 查。平台会改，稿子里提到具体功能时，录之前再看一眼。
**手册里查不到的平台说法，不写进选题和稿子**；行业经验（比如“瑜伽馆是三公里的生意”）可以讲，但别说成平台规则。

## 能投哪些笔记（《聚光可投笔记说明》《聚光笔记投放场景说明（含KOB、KOS）》）

| 笔记 | 怎么投 |
|---|---|
| 我的笔记 | 品牌专业号自己发的，直接投 |
| 蒲公英合作笔记 | 蒲公英下单的博主笔记，聚光里直接选 |
| 授权笔记（KOB） | 品牌代投旗下门店 / 经销商专业号的笔记；在「工具—账户工具—授权关系管理」发起授权，对方同意 |
| 员工笔记（KOS） | 品牌给员工号的笔记投流 |
| 主理人笔记 | 品牌关联的主理人发的笔记；只支持产品种草、电商推广，不支持客资收集 |
| 合作广场笔记 | 素人 UGC 笔记，拿到授权后投，见下 |

## 合作码 / 合作广场（《小红书「合作广场」产品手册》）

- **没报备的笔记也能投**：作者在笔记右上角「…」打开合作码，发给品牌；品牌在「工具—创意工具—合作广场—合作内容管理」输入合作码添加，不用再走授权。品牌也可以在合作广场里主动挑笔记发授权，作者 14 天内同意。
- **只对小号开放**：作者粉丝 < 1 万、已实名、满 18 岁，同时满足；粉丝超过 1 万，合作码自动关闭。一万粉以上的走蒲公英。
- 品牌要给作者设分成：粉丝 < 1000 可以设 0；1000~1 万最低 3%（或一口价最低 150 元，需开白）。单篇分成上限 5000。
- 一篇笔记可以被多个品牌投。作者删笔记，广告自动下线。
- 口碑通不再新开，合作码保留，并进合作广场。

## 员工号 KOS（《企业员工号（KOS）使用手册》）

- 新版员工号：企业在「专业号平台—账号管理—员工号」申请，是**归企业的新账号**，员工用实名个人号绑定、在 app 里切换登录。600 元/年/个，2026-08 起所有企业专业号（含个体户）都能申请，数量不限。
- 员工离职：解绑、换人接着用，号留在企业。
- 企业能看、能回员工号的私信；能在聚光给员工号的笔记投流。
- 旧的“员工个人号授权”模式 2026-10-31 以后不能再用。

## 定向（《定向能力「用户定向」功能说明》《定向能力「搜索主题」功能说明》）

- **年龄只能按档选**：18-22、23-27、28-32、33-40、41-50、50 以上。不要写“25 到 40 岁”这种选不出来的范围。
- **地域最细到区县**，没有“门店周边几公里”。可选：居住在该地区的用户 / 居住或意图在该地区的用户（含搜索里带这个地名的人）/ 所有用户。
- 定向类型二选一：智能定向，或高级定向（行业人群、行业兴趣、关键词兴趣、关键词行为、人群包）。
- 关键词行为：最近 3/7/15/30 天搜过、互动过、看过某关键词内容的人（信息流）。
- 搜索计划默认开「定向拓展」，会突破性别、年龄设置。
- 搜索主题：关键词、高潜词包（客资收集默认勾选）、智能拓词，三者取并集。匹配方式有精准（可开精准包含）和短语。每个单元最多 1000 个关键词。
- 找词工具：词根拓词、用户路径拓词、行业推词、笔记推词；推词看板有蓝海词、同行买词、黑马词、上下游词，竞争指数、月搜索指数、市场出价。

## 数据

- 搜索词数据在「数据—定向报表」（搜索主题、搜索词、人群包），可下载。别写成“搜索词报告”。
- 否词：「搜索推广否词工具」，在单元里「设置广告否词」。

## 改计划和成本保障（《「客资收集」账户成本保障产品手册》）

- 想拿成本保障赔付：一个单元一天改出价 ≤ 2 次、每小时 ≤ 1 次；一天改定向 ≤ 2 次。账户每天转化 ≥ 3 个。
- 学习期：只有「应用下载」手册写了“前 4 天、10 个转化”，客资类没有统一说法，稿子里别写天数。

## 门店（《「产品种草」门店组件说明》）

- 门店页（POI）由专业号在「专业号平台—门店管理—关联门店」认领，要交资质；一个专业号可以关联多家门店。
- 投放挂「门店组件」目前只支持「产品种草」营销诉求。

## 行业

- 瑜伽、普拉提、健身属于「生活服务—运动健身」。生活服务内容规则：不承诺效果、不夸张、不超出功效范围、不低俗；不得把日常情绪低落说成抑郁、紧张说成焦虑症。
- 帮助中心「行业专区（成长品牌）」有双月获客指南（运动健身在「文体娱乐」，成人兴趣在「教育培训」），带热搜词、蓝海词和投放节奏，出新角度时可以去翻。例：运动健身“同城门店词搜索集中、内容供给分散，按城市 + 商圈建内容线几乎没有竞争”。
