# 细分二：封面标题（给一条选题，出封面）

来自云蔓 98 张封面逐张读字 + 收藏数（详细拆解：`~/wechat-content-bot/内容系统/02_对标/云蔓_封面标题.md`）。

## 封面字 ≠ 笔记标题

笔记标题给搜索看，长一点、带行业词；封面字给刷到的人看，短、带"你 / 她"，像一句话在戳人。
例：笔记标题"成交高端客户，千万不要跪舔！"，封面是"你太老实 / 才成交不了有钱人"（收藏 1075）。

## 版式（云蔓全号几乎一个模子）

- 真人半身出镜，占画面上 2/3
- 两行字压在中下部，半透明黑条或白条打底，粗黑体带描边
- 第一行白字：说谁 / 什么情况（4~9 字）
- 第二行黄字、字更大：结果或判断（4~9 字）
- 左上角一个小的系列标签

## 按选题类选公式

| 选题类 | 封面公式 | 云蔓原型 | 格式示范（宠物医院） |
|---|---|---|---|
| B 避坑 | **你的毛病 / 后果** | 你太老实 / 才成交不了有钱人（1075） | 你封面太像病历 / 主人才划走不看 |
| A1 跨界 | **她把 X 加到 Y / 获客结果** | 她把疗愈加到家教 / 赚了1个亿（328） | 她把养老加到宠物医院 / 主人自己找上门 |
| A2 升级 | **别做 X！/ 要做 Y** 或两行反差判断 | 别做移民中介！/ 做一个值钱的身份规划师 | 别只做看病的！/ 做主人信的家庭医生 |
| A3 人群 | **两行反差判断** | 珠宝赛道 / 越发广告越难成交 | 养老猫的主人 / 才是你的大客户 |
| F 故事 | **身份 + 经历** | 家庭破产的我 / 不服输的10年（353） | 身份一行 + 经历一行，按她当次给的真实经历写 |

最后一列**只示范句式，不能直接用**（当前行业就是宠物医院时也要重新写）。每次都按当条选题重新写，并对照 `~/wechat-content-bot/内容系统/01_选题/已出选题.md`，不能和历史封面只差行业名。

系列标签从这几个里选：**获客避坑 / 投放实操 / 跨界打法 / 我的故事**。

## 规则

- **"你的毛病"要是老板愿意承认的**（太老实、回价太快、太勤快），不要是骂人的词。同一个选题，云蔓写"你太老实"收藏 1075，写"跪舔"只有 27。
- 第二行是一句判断，不是一条信息。
- **不写金额**：不用"赚了 N W""1个亿""月入"。云蔓用得最多的"她靠 X 赚了 N W"中位只有约 13。换成获客结果：家长自己找上门、私信多了、不再被比价。
- 不用"下一个风口""将诞生一批富人""10大赛道"，全部不爆。
- 每行不超过 9 个字。缩写会产生歧义时（如"家庭教育"缩成"家教"会被当成请家教），换个说法，不要硬缩。
- 不出现微信号、"包录取"、功效词、别家机构名字。

## 单独出封面时的输出格式

先判断这条选题属于哪类，然后给 3 个备选：

| # | 标签 | 第一行（白） | 第二行（黄） | 用的公式 |
|---|---|---|---|---|

最后推荐一个，一句理由。如果涉及她的个人经历，提醒她确认说法和真实情况一致。
