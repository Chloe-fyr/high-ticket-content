# 细分一：选题（给一个行业，出 10 条）

## 先查元选题库（2026-11-09 建，排在第 0 步之前）

`~/wechat-content-bot/内容系统/01_选题/元选题库.md` 是香菜自己的元选题库：36 个固定句式，加一张"元选题 × 行业"总表。
- 出题时，**每条选题先从库里挑一个元选题**，再套这个行业的 X / Y / Z（库里第二节有各行业怎么填）。优先挑这个行业那一列的空格子、推荐度 ✅ 的。
- 输出表格加一列"元选题编号"（如 M01、T03）。实在套不上的单条选题写"—"，10 条里最多 2 条。
- 出完把编号回填到总表对应的格子里（写了稿填文案编号，只出选题填"选"）。新行业没有那一列就加一列，第二节也补上这个行业的 X / Y / Z。
- 下面的配比（4B / 2A1 / 2A2 / 1A3 / 1F）照旧，元选题的"类"列已经标了对应哪一类。

## 第 0 步：先去重，再出题（2026-10-30 香菜明确，任何行业都适用）

香菜反馈过：连续几次出的选题都一样。原因是规则里写死了现成例子、只"标出重复"不"换掉重复"、也没有出题记录。所以现在每次出题前必须先做这一步：

1. **读历史**，三个地方都要读：
   - `~/wechat-content-bot/内容系统/01_选题/已出选题.md`（**所有行业**的历史选题，不只当前行业）
   - `~/wechat-content-bot/内容系统/01_选题/` 下所有选题卡
   - `~/wechat-content-bot/内容系统/03_文案/` 和 `03_文案/_不用/` 里每篇稿子的标题
2. **判断重复**，以下任何一条都算重复：
   - 同一个行业：**同一个细分点 + 同一个错误**（比如都是"选词：抢大词"）
   - 同一个行业：A1 用了同一个 X；A3 用了同一类人群
   - **跨行业：同一个细分点 + 同一个错误，只是换了行业名**（比如留学"投聚光别抢大词"和瑜伽"投聚光别投全城"，本质都是"一上来铺太大"）。她所有行业都发在同一个号上，粉丝会看到两条一样的
   - 标题句式和历史上某条只差行业名
3. **重复就换，不能交。** 不要出完再在末尾说"第 X 条重复了"。
4. 一个行业某个环节的细分点用完了，就在表前写一句"XX 环节的细分点在这个行业已用完"，然后换别的环节补齐，同时请她给新的数据来源（见"新角度从哪来"）。

核心规律：
- **标题和选题都要点名行业的人**："<行业>做<事>"。同样讲做 IP，点名行业的（珠宝人做自媒体，1591）远好于泛讲的（年入千万的 IP 都有这 3 个特质，5）。
- **一个行业一条视频，选题本身就是客户分类**，结尾用"评论区扣『X』"区分是哪类老板。
- 每条选题在写稿时用哪种结构，见 `scripts.md` 第 1 步：B / A2 / A3 → 结构 A，整套打法 → 结构 C，A1 → 结构 E，F → 结构 G。

## 笔记标题怎么写（2026-10-31 按云蔓 198 篇）

**公式：两段式，前半句点名行业的人 / 场景，后半句是判断或后果。14~20 字。**

| 云蔓原标题 | 收藏 | 公式 |
|---|---|---|
| 珠宝人做自媒体，发图只会被拉黑 | 1591 | 【行业人】做【事】，【常见动作】只会【坏结果】 |
| 成交高端客户，千万不要跪舔！ | 1075 | 【场景】，千万不要【错误】 |
| 老板必看\|想赚💰，别做品牌！ | 933 | 【人群】必看\|想【目标】，别【常见做法】 |
| 2024知识付费变天了，再不转型就晚了 | 271 | 【时间】【领域】变天了，再不【动作】就晚了 |
| 笔记流量总是几百❓明白一点至少翻10倍 | 138 | 【痛点问句】，明白一点【结果】 |
| 她把疗愈加到家庭教育里，从此接单到手软！ | 328 | 她把 X 加到 Y，从此【结果】（A1 专用） |

规则：
- **后半句的后果要具体、要狠**："只会被拉黑""钱全白花""再不改就晚了"，不要"要注意""选错了"这种软的
- **不炫耀金额**：同一篇稿换标题重发，带金额的标题平均只有同篇中位的 0.82 倍；"自从做了高端市场，瞬间到了千万量级"13 vs"成交高端客户，千万不要跪舔"1075
- 不用"将诞生 / 风口 / 暴利 / 一把撸了"
- **公式对了就够，不用反复抠字**：同一篇稿几乎一样的标题也能差 6 倍，标题措辞的平均影响只有 10%~30%，选题和稿子本身更重要
- 最多一个感叹号或 emoji

B 类要讲成"高客单通用、用这个行业举例"：云蔓最爆的那条是所有老板都关心的成交问题，单讲某个行业的反而不爆。

**AI 要多讲（2026-10-31 香菜明确）**：10 条里至少 3 条落在"4 AI 提效"模块（B / A2 / A3 都可以用 AI 打法），不再只放 1 条。

**A3 人群别选本身就是独立赛道的细分（2026-10-31 香菜否过：留学 + 艺术留学）**：做艺术留学的机构本来就专做艺术，不会有老板"商科做久了转艺术"。A3 选的是同一类机构顺手就能接、但大家没认真接的人群或场景（如低龄家长、在读学生），不选需要另起一家机构的细分方向。

**F 和所有稿子都不提线上课、线下课、陪跑和香菜自己的业务**（2026-10-31 香菜明确），除非她当次要求。F 故事从她的投放、做号经历里找切口，不从上课场景找。

F 类每次都要换一段经历或一个新切口，不能和历史上的 F 条讲同一段。她没给过新经历时，F 用她已确认的经历换个角度，并在"要补的素材"里写明请她确认。

## 选题讲什么：技术流获客，不讲内容创作（2026-10-30 香菜第二次明确）

香菜的原话："跟获客有关系吗？你讲的还是怎么去做内容，而且抠得很细……我更擅长的是偏技术流这套。"

**香菜只做前端获客**：她是搞流量的，不碰客户的产品和销售。不出这类选题：私信话术、报价、体验课、加微信跟进、成交、定价、课程/产品设计，以及私域（朋友圈怎么发、社群、公转私，2026-11-04 明确不做）。这些最多在稿子里一句带过（如"流量来了，私信接不住也白搭"）。

**她最擅长、选题主要从这里出的是技术流**，每条选题从下面六块里选一块：

| 模块 | 能讲的打法（轮换着用） |
|---|---|
| 1 账号矩阵 | 蓝 V 号、创始人 IP 号、员工/顾问 IP 号、KOL、KOC、素人号各自干什么；几个号怎么分工、不同质化；蓝 V 什么时候开；矩阵从几个号起步、什么时候加号 |
| 2 养号起号 | 新号前几天做什么、标签怎么养准、老号怎么重启、一号一个真人（真实员工、真实身份）、怎么判断号养好了、第一篇发什么 |
| 3 素材生产 | 一篇跑通的素材怎么拆成多个版本、图文还是视频、混剪和批量出图、一套素材怎么分给不同的号、素材库怎么搭 |
| 4 AI 提效 | AI 批量出选题和初稿、改写成不同号的版本、出图、从评论和私信里提取搜索词、整理投放数据；一个运营靠 AI 管几个号 |
| 5 发布与分发 | 多个号的发布节奏和时间、避免被判重复、搜索词怎么分给不同的号、直播怎么接矩阵、评论区和主页怎么互相导流（合规） |
| 6 投放 | 聚光投哪个号、投哪篇、和矩阵怎么配合、选词、素材疲劳、预算节奏、过审 |

**选题讲框架，不讲操作（2026-11-02 香菜明确）**：选题以"<行业>账号怎么做到<结果>"这种整套模型为主（像云蔓"珠宝人做自媒体""移民 IP 怎么做"），覆盖定位 / 内容 / 人设 / 包装 / 流量 / 承接，不再出"聚光某个按钮怎么设"这种操作级选题。下面"技术流六大模块"仍可作为某一步的内容，但不单独拆成操作题。

**选题要自带信息差（2026-11-01 香菜明确）**：每条选题的"核心判断"要是老板听完会说"不会吧"的反常识结论，而且背后有一个能讲清楚的机制。
- 优先从**投放后台的冷知识**出题（先看 `juguang.md`）：系统默认开着的选项、平台规则里的门槛和限制、报表里能看到但老板没看过的东西
- 少出"评论区怎么回""几点发""要让顾问出镜"这类运营规范题：老板听完只会说"对，应该的"，香菜说过这类"很浅显"
- 自查：把核心判断念给一个老板听，他是点头，还是愣一下？点头的换掉

**粒度：一条选题讲一套打法，不讲一个小技巧。**
- 学云蔓：他一条"移民做 IP"讲的是整套模型（产品 → 人设 → 流量 → 触达），每一点一句话带过，不抠细节。
- 自查：老板看完，能不能说出"原来这一块要这么搭"？只学到"开头别自我介绍""置顶放三篇"这种小技巧的，**不合格**。
- 每条都要能回答"这么做，客资为什么会变多"。回答不了的，就不是获客选题。

**内容和用户共情不单独做选题。** 封面怎么写、开头怎么说、怎么和家长共情，最多在稿子里一句话带过，比如"内容一定要让客户产生共情"，不展开讲。

**平台事实别说错**（2026-10-31 香菜纠正）：没报备的达人笔记，也能通过合作码投聚光，所以不能用"不报备就投不了 / 加热不了"当论据。写平台功能时，先对 `juguang.md`，手册里查不到的说法不写进选题和稿子。

**合规底线**：素人号、KOC 必须是真实的人（真实员工、真实学员授权分享、报备的合作达人），不教假扮客户、批量注册、规避实名或平台检测。

同一批 10 条里，同一个模块下不能有两条讲同一套打法。

## A1 跨界组合怎么出（2026-10-30 香菜确认，按 016 普拉提+疗愈、017 瑜伽+亲子 的写法）

学云蔓：**两个行业拼成一个新模式**（疗愈 + 家庭教育），这是他号上最容易爆的一类（收藏中位数约 214）。香菜要的就是这种"瑜伽 + 疗愈""瑜伽 + 亲子"式的组合。
A1 是"不碰产品"的例外：可以讲拼出来的新模式，但**落点放在获客结果**（谁会自己找上门、为什么不再被比价、谁会帮你拉人），课怎么排、怎么定价不展开。

一个 X 要**三条全过**：

1. **X 的人群和这个行业的客户重合，痛点更深**：拼上 X 之后，客户的焦虑能被讲透（写法 B）。
2. **拼起来有一个获客结果**：不再被比价、客户自己拉人、搜 X 的人也找过来。
3. **合规**：不借 X 说功效（如借疗愈说"治失眠"、借产后说"修复"），不承诺效果。

**X 必须和这个行业天然挨着：老板一听就觉得"对，我的客户本来就需要这个"。** 自查：老板听完会不会觉得"这俩怎么可能放一起"？会，就不合格。香菜否过：留学 + 疗愈（2026-10-30）。

**想不出来就参考云蔓的选题**，从他做过的行业里找和当前行业同一群客户的那个：
- 瑜伽、普拉提这类身心类门店：疗愈、亲子最合适（云蔓的疗愈 + 家庭教育、国学 + 疗愈）
- 留学：移民 / 身份规划（云蔓"别做移民中介，做身份规划师"）、家庭教育、职业规划，都是同一群送孩子出国的家庭
- 其他行业：先列出云蔓做过的行业（疗愈、家庭教育、移民、海外房产、海外保险、金融、珠宝、国学、艺术），挑客户重合的那个

**疗愈、亲子在身心类行业里可以反复用。** 云蔓 4 条 A1 里有 3 条都是疗愈（疗愈 + 家庭教育 340、国学 + 疗愈 100、艺术 + 疗愈 24），同一张封面还发过多次。爆不爆看 X 戳不戳痛点，不看新不新。
- 不要为了"新"去找冷门 X（香菜否过：跑步圈、咖啡馆、旅行、备婚都不合适）。
- 同一个行业再用疗愈、亲子时，换一个角度：换获客结果（不再被比价 / 客户自己拉人 / 客户自己找上门），或换门店（瑜伽馆 / 普拉提馆），不和已写的稿子同一个标题、同一个封面。
- 已经写好的同 X 稿子（如瑜伽的 016 疗愈、017 亲子），出选题时可以直接把它放进 A1 名额，注明"沿用文案 0XX"。

## 新角度从哪来

不要只靠这份文件里的细分点表。她给过新材料时，优先从材料里挖：

- 聚光关键词表：低竞争、高出价的词，往往对应一个没人讲的获客问题
- 新的对标笔记、评论区里老板的提问
- 她最近线下课、陪跑里遇到的真实问题

## 输出格式

先一行写明：行业、受众（该行业老板）、这个行业的广告风控要点。然后一张表：

| # | 类 | 笔记标题 | 封面标题（两行） | 模块-打法 | 核心判断（一句可以被反驳的话） | 结尾口令 | 拍之前要补的真实素材 |
|---|---|---|---|---|---|---|---|

- 笔记标题按上面"笔记标题怎么写"的公式，20 字以内，最多一个感叹号或 emoji。
- 结尾口令：留学行业一律写"指南"（资料统一是"留学机构的企划线上指南"）；其他行业同一个行业只用一个口令。
- 封面标题按 `covers.md` 的规则写，格式"【标签】第一行 / 第二行"，每行不超过 9 字。
- 封面标题也要去重：不能和历史选题的封面只差行业名。

表后给：
- **建议先拍的 3 条**，各一句理由
- **这个行业的风控提醒**
- **去重自查**：一句话说明读了哪些历史、跳过了哪些已用过的细分点 / X / 人群
